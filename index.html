Python Programming — Basics

A clean, single-page mini-site that explains core concepts with examples — made for beginners.

What is Python?

Python is a high-level, interpreted programming language with readable syntax. It's widely used for web development, data science, AI, scripting and automation.

Variables & Data Types

Store values in names. Common types: int, float, str, bool.

name = "Joy"
age = 20
pi = 3.14159
is_student = True

Input & Output

Print to screen and read user input.

print("Hello, World!")
name = input("Enter your name: ")
print("Hi,", name)

Conditions (if / else)

Branch logic using comparisons.

age = 18
if age >= 18:
    print("You are an adult")
else:
    print("You are a minor")

Loops

Repeat actions: for-loops and while-loops.

for i in range(5):
    print(i)

count = 1
while count <= 5:
    print(count)
    count += 1

Functions

Reusable blocks of code.

def greet(name):
    return "Hello " + name

print(greet("Joy"))

Why learn Python?

Easy to learn, huge community, and paths to AI, web, and data science. Great first language.
